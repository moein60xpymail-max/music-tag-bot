# Music Tag Bot v4.2

## تغییرات نسخه 4.2
- پس از زدن `Finish Uploading`، فهرست آلبوم بر اساس شماره ترک مرتب می‌شود؛ شماره دیسک نیز در ترتیب لحاظ می‌شود.
- مقادیر شماره ترک/دیسک با قالب‌هایی مانند `03` و `3/12` شناسایی می‌شوند.
- ترک‌های بدون شماره در انتهای فهرست می‌مانند؛ شماره‌های تکراری به‌صورت خودکار بازنویسی نمی‌شوند.
- امکان انتخاب چند ترک و اعمال یک فیلد مشترک (Artist، Album Artist، Album، Genre، Composer، Publisher یا Year) فقط روی ترک‌های انتخاب‌شده اضافه شد.

## تغییرات نسخه 4.1.1
- فرمان مدیریت کاور Unreleased Track از کیبورد اصلی حذف و به منوی همبرگری تلگرام با دستور `/unreleasedcover` منتقل شد.

## تغییرات نسخه 4.1
- مدیریت کاور پیش‌فرض Unreleased Track برای ثبت، جایگزینی و حذف تصویر.
- هنگام انتخاب Unreleased Track می‌توان کاور پیش‌فرض را اعمال کرد، کاور فعلی را حفظ کرد یا عملیات را لغو کرد.
- این قابلیت در حالت‌های Single، Album و Archive کار می‌کند و فقط فایل/ترک انتخاب‌شده را تغییر می‌دهد.

## نکته نگهداری کاور
تصویر پیش‌فرض در مسیر `DATA_DIR/unreleased_track_cover.jpg` ذخیره می‌شود. اگر فضای محلی هاست با Restart یا Redeploy پاک شود، تصویر باید دوباره ارسال شود.

## نصب
محتویات پوشه `v36work` را با حفظ ساختار فایل‌ها در ریشه مخزن GitHub قرار دهید و سرویس را Redeploy کنید.

## متغیرهای محیطی
- `BOT_TOKEN`: توکن ربات تلگرام
- `DATA_DIR`: مسیر اختیاری داده‌ها (پیش‌فرض `data`)

فرمان اجرا: `python bot.py`.
