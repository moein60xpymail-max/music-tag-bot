# Music Tag Bot v4.1

## تغییرات نسخه 4.1
- بخش «نسخه» اکنون شماره نسخه و خلاصه تغییرات همان نسخه را نمایش می‌دهد.
- منوی «مدیریت کاور Unreleased Track» برای ثبت، جایگزینی و حذف تصویر پیش‌فرض اضافه شد.
- هنگام انتخاب Unreleased Track می‌توان کاور پیش‌فرض را روی همان آهنگ اعمال کرد، کاور فعلی را حفظ کرد یا عملیات را لغو کرد.
- این قابلیت در حالت‌های Single، Album و Archive کار می‌کند و فقط فایل/ترک انتخاب‌شده را تغییر می‌دهد.
- اگر کاور پیش‌فرض ثبت نشده باشد، ربات آن را اعمال نمی‌کند.

## نکته نگهداری کاور
تصویر پیش‌فرض در مسیر `DATA_DIR/unreleased_track_cover.jpg` ذخیره می‌شود. اگر فضای محلی هاست با Restart یا Redeploy پاک شود، تصویر باید دوباره از منوی مدیریت کاور ارسال شود.

## نصب
محتویات پوشه `v36work` را با حفظ ساختار فایل‌ها در ریشه مخزن GitHub قرار دهید و سرویس را Redeploy کنید.

## متغیرهای محیطی
- `BOT_TOKEN`: توکن ربات تلگرام
- `DATA_DIR`: مسیر اختیاری داده‌ها (پیش‌فرض `data`)

فرمان اجرا: `python bot.py`.
